# 最新尾部篮子 v3

默认机器人：`../b2z1_0815_with_basket_v3.urdf`。此目录包含最新 CAD 源文件与独立于试验报告的模型参数清单。

- 源文件：`零件2.SLDPRT`；SHA-256 见 `basket_properties.json`。
- 外尺寸：450 × 250 × 160 mm；壁厚约 1.5 mm。
- 尾沿：约 15 mm；尾部主斜面约 30°；CAD 保存的离散网格包含底部过渡。
- 质量：0.2 kg 为沿用设定，未经实测；按 CAD 壳体均匀质量分布计算质心和惯性。
- 固定安装：父 link `base`，子 link `tail_basket`；平移 `(-0.30, 0, 0.13) m`，旋转为零。
- 网格：`../meshes/basket_v3/`，1 个外观 OBJ + 103 个凸碰撞 OBJ，单位米，保留空腔与前后开口。
- 不增加可控关节，原有 19 维动作契约不变。

几何数据来自 CAD 保存的显示三角网格，不是精确曲面 B-rep 重建。JSON 中的 CRC、体积及采样结果记录了模型生成时的离线几何校验；本次发布另行检查 URDF 引用、关节契约、网格及源 CAD 哈希。新版接入后的 Isaac/PhysX 动态运行、载重行走与卸料尚待验证。

本发布包只包含模型资产，不包含独立试验的查看器、轨迹、报告或试验结果图片。
