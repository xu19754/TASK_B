# 随机三件测试：夹爪速度超限原因分析

**主要问题是可动夹爪承担了铲扫接触载荷，而控制器仍把它的位置目标固定为 −0.08 rad。物料使夹爪偏离目标；接触脱开时快速回位，或卡料时持续受外力转动，超过实际速度阈值。**

本次按原始布局和原路径重新运行全部 7 个失败案例，逐毫秒复制物理步前后的数据。7 例的拒绝时间和七关节速度向量均与原记录一致（速度一致性断言容差 1e−9）。观察器不改变原模型或物理状态；116 个受保护文件保持不变。

## 超限的是哪一个量

- 7/7 为 `jointGripper` 的实际角速度；其限值为 0.25 rad/s，保护实现还包含 0.0001 rad/s 的数值容差。
- 原路径的前六个臂关节目标峰值不超过 0.02 rad/s；夹爪位置目标一直为 −0.08 rad，目标角速度为零。
- `ArmDiagnostic.step()` 限制的是目标变化速率。MuJoCo 位置执行器限制输出力矩为 ±5 N·m，随后读取实际 `qvel`，超限则回退并暂停。目标限速、力矩限幅、实际速度保护是三件不同的事。
- 本诊断没有在物理求解中设置硬性的实际速度约束；不能把 `VELOCITY[-1] = 0.25` 理解为物理引擎会把速度截断到 0.25。

相关实现：`scripts/basket_arm_viewer.py` 的 `build_scene()`、`step()`；参数来源与正式环境对照为 `taskb_student/robot.py`。MuJoCo 对 `forcerange` 的定义是执行器输出力限幅，见[官方说明](https://mujoco.readthedocs.io/en/3.3.7/modeling.html#force-limits)。

## 5 例：负载脱开后，位置伺服快速回位

夹爪控制近似为以下 PD 力矩（另加模型偏置补偿，然后限幅）：

\[
\tau_m = \operatorname{clip}\left(80(q_{cmd}-q)-8\dot q+\tau_{bias},-5,5\right).
\]

物料抵住夹爪时，接触反力与电机力矩近似平衡。虽然夹爪已经偏离目标，速度仍很小。物料滑过、滚开或脱离接触后，抵抗电机的接触力矩突然消失，控制器仍尝试消除原有位置误差，夹爪快速回位。

以下为 mixed seed=20261027 的直接力学记录；表中电机力矩是在该步实际参与积分的力矩：

| 步结束时间（s） | 夹爪速度（rad/s） | 电机力矩（N·m） | 接触力矩（N·m） | 可动夹爪接触 |
| ---: | ---: | ---: | ---: | --- |
| 51.397 | +0.038781 | −4.5234 | +4.4995 | 糖盒，两接触点 |
| 51.398 | +0.034108 | −4.4920 | +4.4623 | 糖盒，两接触点 |
| 51.399 | **−0.481867** | −4.4573 | **0** | **脱开** |

此时位置误差约 −0.05236 rad（−3.00°）。忽略耦合和再次接触时，过阻尼回位速度的数量级为 `(Kp/Kd) × error ≈ −0.524 rad/s`，与测得的 −0.482 rad/s 相符。这个估算用于解释机制，不是严格的速度上界。

相同机制还发生在 seed=20261128、20261228、20261326、20261327：超限步可动夹爪的接触力矩均变为零，电机仍在消除位置误差。

本模型在这些姿态下夹爪的等效惯量约为 2.9×10⁻⁴ kg·m²；未添加转子折算惯量，关节被动阻尼也为零。与执行器阻尼 8 N·m·s/rad 对应的惯性时间尺度约为 36 μs，快于原 1 ms 物理步，因而会出现很快的回位瞬态。真实传动摩擦、转子惯量和驱动器行为未由这项诊断验证。

## 2 例：持续接触、力矩饱和与卡料

**mixed seed=20261028：** 超限步依然有芥末瓶接触。两个接触点的法向力约 48.7 N 和 43.2 N，对夹爪产生约 +5.002 N·m 的广义力矩；电机已到 −5 N·m 限幅，实际夹爪仍被顶动，从 +0.237812 加速到 +0.250872 rad/s。限力矩本身不能保证在外载下限住实际速度。

**三个糖盒 seed=20261126：** 夹爪偏离目标约 0.19899 rad（11.40°），电机处于 +5 N·m 饱和。该步同时出现物料接触和 `collision_gripperMover_3 ↔ collision_tail_basket_15` 接触，后者法向力约 55.6 N；这是卡料与铲面姿态偏移共同发生的情况。

保持同一时刻前六个臂关节角不变，仅在离线正运动学中对比实际夹爪角与规划假设的 −0.08 rad：

| 铲边端点高度，篮子局部 Z | 第一端（mm） | 第二端（mm） |
| --- | ---: | ---: |
| 用实际夹爪角 −0.278992 rad | 1.941 | 1.458 |
| 用规划夹爪角 −0.08 rad | 20.589 | 20.106 |
| 实际降低 | **18.648** | **18.648** |

平底内表面约为 Z=1.5 mm，实际一端已接近或略越过内底表面。原路径的静态碰撞预检检查目标关节角，不能保证受接触载荷后偏转的真实铲面仍保持该高度。这也解释了为何“规划预检通过”仍可能在动态执行中卡料。

原随机测试的结果文件主要观察步后及保护回退后的状态；本次在物理力求解处捕获到了上述瞬时篮筐接触。不能仅凭原结果的步后接触汇总排除这种接触。

## 数值步长是否造成了假超限

在每例超限前的同一完整状态上，保持该 1 ms 内的控制输入不变，使用独立模型把物理步依次细分到 1/64（15.625 μs）。力矩限幅、碰撞几何与接触规则不变。

| seed | 原 1 ms 步末速度绝对值（rad/s） | 64 个子步内峰值（rad/s） | 临界窗口结论 |
| ---: | ---: | ---: | --- |
| 20261027 | 0.481867 | 0.426247 | 仍超限 |
| 20261028 | 0.250872 | 0.251043 | 仍超限 |
| 20261126 | 0.270829 | 0.253469 | 仍超限，但靠近阈值 |
| 20261128 | 0.416017 | 0.430625 | 仍超限 |
| 20261228 | 0.386725 | 0.204008 | **对步长敏感** |
| 20261326 | 0.495703 | 0.510691 | 仍超限 |
| 20261327 | 0.268197 | 0.273017 | 仍超限 |

因此，当前模型的超限不能全部归为原步长过粗。seed=20261228 的峰值则明显受接触切换与步长影响，不能直接当作可靠的实机速度预测。以上只细分了临界 1 ms，未从初态细步长重跑完整 156.51 s；它不是完整轨迹的收敛性证明，也不改变原 12 组试验的完成/停止记录。

## 修改优先级

1. **让接触控制使用真实夹爪角和角速度。** 当角差或接触力矩增大时，暂停肩肘继续推进，进行小幅退让或抬升；防止持续积累夹爪位置误差后突然回位。
2. **用实际夹爪角计算铲边位置与离底高度。** 当前固定 −0.08 rad 的几何假设在受载时不成立，需要协调补偿或重新规划；同时检查卡在物料和篮底之间的接触。
3. **针对接触段降速并复核细步长。** 降低推进速度可以减小冲击，但仅把整条路径放慢，不能保证消除几何卡料、外力顶动或脱开回位。
4. **保留 0.25 rad/s 与 5 N·m 限制。** 不通过截断测得速度、锁死夹爪或提高阈值来掩盖超限。任何新的控制方案仍需在同组布局下重新验证。

本次只分析原因，没有替换原轨迹或修改正式控制器。结论适用于当前 MuJoCo 诊断；Isaac/PhysX 与整机验证仍需独立完成。

```sh
.venv-basket/bin/python scripts/basket_speed_audit.py --refine
```

`audit.json` 为汇总；每个 seed 的 JSON 包含超限前约 200 ms 的逐步力学记录，NPZ 保存超限前的完整积分状态。原始批次报告仍位于 `reports/basket_v3/random_three_2026-10-26/测试报告.md`。
